## 🔍 Interface Signals

### Input Signals
- `clk` - Clock
- `rst_n` - Reset (active low)
- `valid` - Input valid
- `enable` - Module enable
- `data_in[31:0]` - Input data
- `polynomial[7:0]` - CRC polynomial

### Output Signals
- `ready` - Ready for next transaction
- `busy` - Processing in progress
- `crc_out[7:0]` - Output CRC value
- `error` - Error flag
- `done` - Completion flag

## 💾 Data Types

```systemverilog
// Transaction
class crc_transaction
  rand bit [31:0] data_in
  rand bit [7:0]  polynomial
  rand bit        valid, enable
       bit [7:0]  crc_out
       bit        error, done

// Control signals
logic ready, busy
```

## 🔄 Execution Flow

```
1. Reset assertion (20 ns)

3. Test phase begins
4. Sequences generate transactions
5. Driver applies stimuli
6. Monitor collects responses
7. Predictor calculates expected values
8. Scoreboard compares results
9. Results reported
10. Simulation ends
```
