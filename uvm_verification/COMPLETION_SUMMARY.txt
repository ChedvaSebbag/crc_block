HOW TO USE
═══════════════════════════════════════════════════════════════════════════

QUICK START (2 MINUTES):
  1. cd /Users/chedvasebbag/Downloads/crc/uvm_verification
  2. make compile
  3. make test_all

READ DOCUMENTATION:
  1. START_HERE.txt      - First read this!
  2. README.md           - Quick reference
  3. GUIDE.md            - Full manual
  4. INDEX.md            - File index

RUN TESTS:
  Individual Test:
    make sim_batch TESTNAME=crc_smoke_test
  
  All Tests:
    make test_all
  
  Python Runner:
    python3 test_runner.py --run-all --batch

CUSTOMIZE:
  1. Add sequences to crc_seq_lib.sv
  2. Add tests to crc_test.sv
  3. Modify DUT in tb/crc_dut.sv
  4. Update interface in src/crc_if.sv
