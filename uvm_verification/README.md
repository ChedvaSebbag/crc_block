# CRC Verification Environment - README
# =====================================================

## Project Description
A professional UVM-based verification environment for a configurable CRC hardware block.
The environment is designed using industry best practices and includes reusable components,
multiple test scenarios, reference modeling, scoreboarding, and functional coverage.

Key features:
- UVM Framework
- Modular and reusable verification components
- Multiple test scenarios (random, directed, edge cases)
- Predictor and scoreboard architecture
- Clear separation between design and verification

## UVM Components Overview
 
# UVM Components Overview

## Transaction – `crc_transaction.sv`
Represents a single CRC operation and contains both stimulus and observed results:
- **data_in** – 32-bit input data  
- **crc_init** – initial CRC value  
- **crc_select** – selects CRC type (CRC-3 / CRC-8 / CRC-16 / CRC-32)  
- **data_valid** – indicates a valid transaction  
- **Observed outputs:** `crc_out`, `crc_valid`, `busy`

---

## Driver
Drives transactions from the sequencer onto the DUT interface  
and handles timing and handshake with the DUT.

---

## Sequencer
Controls the order and flow of transactions generated by sequences.

---

## Monitor
Observes DUT inputs and outputs and forwards completed transactions  
to the predictor and scoreboard via analysis ports.

---

## Agent
Encapsulates the **driver**, **sequencer**, and **monitor**  
into a single reusable verification component.

---

## Predictor
Implements a reference CRC algorithm and calculates the expected CRC result  
based on the transaction fields.

---

## Scoreboard
Compares predicted CRC results with the actual DUT output  
and reports matches and mismatches.

---

## Environment
Instantiates and connects all verification components  
to form the complete UVM verification environment.

---

# Test Scenarios

- **Smoke Test** – basic random transactions to verify fundamental functionality  
- **Directed Test** – deterministic patterns and specific CRC selections  
- **Edge Case Test** – all-zeros, all-ones, and alternating data patterns  
- **Multiple CRC Modes** – verification of CRC-3, CRC-8, CRC-16, and CRC-32 operation  

---

# Running the Simulation

## Using scripts
```bash
cd uvm_verification
bash sim/run_sim.sh
```
--

## Running a specific UVM test
```bash

vsim -c -do "run -all; quit" \
    +UVM_TESTNAME=crc_smoke_test \
    crc_tb_top
```
