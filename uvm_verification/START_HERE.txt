🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Problem: "vlog not found"
Solution: Add simulator to PATH
  export PATH=$PATH:/opt/modelsim/bin

Problem: Compilation error
Solution: Clean and recompile
  make clean && make compile

Problem: Test timeout
Solution: Increase timeout in crc_tb_top.sv line 77

Problem: UVM not found
Solution: Source UVM installation
  source /opt/modelsim/uvm/uvm-1.2/install/install.sh

See GUIDE.md for more troubleshooting
